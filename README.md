PokéGame – PokéAPI

About the Project
A Pokémon-themed web game developed using HTML, CSS, and JavaScript. The game uses PokéAPI to retrieve Pokémon data and includes 12 levels.

Features
- 12 playable levels
- Pokémon data retrieved from PokéAPI
- Interactive gameplay
- Pokémon information and images
- Web-based user interface

Technologies Used
- HTML5
- CSS3
- JavaScript
- PokéAPI (REST API)

What I Learned
- Fetching data from an external API
- Working with JSON data
- Using JavaScript for interactive functionality
- Manipulating HTML elements with JavaScript
- Organizing and styling a web application

Maybe Future Improvements
- Add more levels
- Improve the user interface
- Add more gameplay features
- Improve responsiveness across devices
